# 実験結果の分析手順

学会の学生セッション向けに、実験結果を分析してまとめるための手順です。

この実験は、将棋の指手の並びだけを与えて学習したモデルが、盤面や持ち駒を内部でどこまで持っているかを調べたものです。
モデルには盤面の情報（駒の位置）を一度も与えていません。
背景と実験の構成は[research_overview.md](research_overview.md)と[将棋.pdf](../将棋.pdf)にあります。この2つとこの手順書で足ります。

## 1　CSVを作る

結果の`tar.gz`を受け取ったら、次を実行します。

```bash
./scripts/prepare_student_data.sh results.tar.gz student_data
```

`student_data/`に3つのCSVができます。Excelでもそのまま開けます。

| ファイル | 内容 |
|---|---|
| `runs.csv` | 1行が1モデル。条件4種 × シード3個 = 12行 |
| `summary.csv` | 1行が1条件。3シードの平均と標準偏差 |
| `columns.csv` | 列の意味と単位 |
| `baselines.csv` | 比較の下限。**モデルの成績ではありません** |

まず`columns.csv`を読んでください。 列名だけでは意味が分かりません。

## 2　条件とシードを理解する

`条件`は4種類あります。

| 条件 | 内容 |
|---|---|
| RAPなし | 指手の並びだけを与えた基本の条件 |
| RAP q=0.15 | 指手の15%に「どの駒を動かすか」の情報を混ぜて学習した条件 |
| RAP q=0.25 | 同じく25%混ぜた条件 |
| AP(参考) | 100%混ぜた条件。評価時にも正解を与えるので、**他と同じ土俵ではありません** |

`シード`は乱数の初期値です。同じ条件でも初期値が違えば結果が変わります。3個あるのは、条件の差と偶然の差を区別するためです。

AP は参考値です。他の3条件と同じ表に並べないでください。

## 3　最初にやること

`summary.csv`を開いて、次の列を確認してください。

```
指手top1_平均 / 指手top1_標準偏差
盤面macroF1_平均 / 盤面macroF1_標準偏差
```

**条件間の差が、標準偏差より大きいかを確かめます。**

- 差が標準偏差より小さい → 偶然の範囲かもしれません。「差がある」とは書けません
- 差が標準偏差より明らかに大きい → 条件の効果として書けます

ここが分析の中心です。平均だけを見て「向上した」と書かないでください。

## 4　確認するところ

### 盤面と持ち駒を読み取れているか

`盤面macroF1_平均`と`盤面macroF1_多数派_平均`を比べます。多数派は「いつも一番多いクラスを答えた場合」の値で、比較の下限です。これを大きく超えていれば、モデルの中に盤面の情報があることになります。

`選択層`はTransformerの中間12層のうちどの層を使ったかです。
`盤面macroF1`と`盤面macroF1_最終層`を比べると、途中の層と最後の層のどちらが読み取りやすいかが分かります。

### ルールを与えていないのに合法か

`top1合法率`を見てください。**モデルにはルールも合法手の一覧も与えていません。** それでも生成した指手が合法なら、その時点の盤面を追えていないと説明がつきません。

`指手top1`（棋譜と一致した割合）は、`baselines.csv`の`暗記ベースライン_指手top1`と比べてください。同じ局面を学習データから探して答えただけで届く水準です。これを超えた分が、丸暗記では説明できない部分です。

### RAPは効いたか

`指手top1`と`盤面macroF1`を条件間で比べます。差が標準偏差に埋もれていれば「効果は確認できなかった」が結論です。

`Start_top1`と`End_top1`も見てください。ここは注意が要ります（第5節）。

### 持ち駒への依存

`指手依存差_第12層`が正なら、駒打ちを続けたときに持ち駒を読み取りやすくなっています。

`遮断_関連履歴の変化`と`遮断_対照履歴の変化`を比べます。
関連する過去の指手への参照を切ったときだけ大きく下がるなら、そこを見て判断していることになります。

## 5　書けないこと

結果の読み違いで結論が逆になる箇所があります。

**`Start_top1`について。** RAPなしの値が極端に低くても、「RAPなしのモデルは駒種から移動元を追跡できない」とは書けません。
RAPなしのモデルは学習中に駒種の情報を一度も見ていないため、評価時にそれを与えること自体が想定外の入力となります。
正しくは「RAPは駒種を手がかりにする経路を作る」です。条件間の公平な比較には`End_top1`を使ってください。

**AP について。** 評価時にも正解の駒種を与えているので、他の条件より数値が良くて当然です。「APが最も優れている」とは書けません。

**「盤面を理解している」と書かないでください。** 言えるのは「盤面の情報が隠れ状態から読み取れる」までです。読み取れることと、モデルがそれを使って指手を決めていることは別です。

**「強い」「棋力が高い」と書かないでください。** 測ったのは棋譜の指手と一致した割合で、手の良し悪しではありません。

## 6　原稿の構成

学生セッションは2ページ程度です。次の4節構成にしてください。
スライド（[将棋.pdf](../将棋.pdf)）の流れとほぼ同じなので、スライドを順に見ながら書けます。

| 節 | 分量の目安 | スライドの対応箇所 |
|---|---|---|
| 1 はじめに | 1/4ページ | 背景・目的 |
| 2 指手系列による次手予測 | 1/2ページ | 指手表現、駒種注釈、将棋への拡張、線形プローブ |
| 3 実験と考察 | 1ページ | ― （今回の結果） |
| 4 おわりに | 数行 | ― |

### 1 はじめに

3つのことを書きます。

- **何を扱うか。** 将棋の指手の並びだけを与えて学習したTransformerです。盤面は一度も与えていません
- **なぜ調べるか。** 次の指手を当てられたとしても、モデルが盤面を追っているのか、指手の並びの統計を覚えただけなのかは区別できません
- **何を測るか。** 隠れ状態から盤面と持ち駒を読み出せるかを、線形プローブで測ります

先行研究に1〜2行触れてください。 チェスやオセロで同じことが調べられており（文献［1］［2］）、本研究はそれを将棋へ広げたものです。
将棋を選ぶ理由は持ち駒です。持ち駒は盤の上に座標を持たないため、過去にどの駒を取りどの駒を打ったかをたどらないと復元できません。チェスにはない依存関係です。

### 2 指手系列による次手予測

**測り方を説明する節です。結果は書きません。** 次の4つを、図か式を1つ入れて説明します。

- **指手の符号化。** 通常の移動は2トークン、成りと駒打ちは3トークン
- **入力系列。** `<BOS> <MOVES>` に続けて指手を並べる。**盤面の情報は入りません**
- **RAP。** 学習時にだけ、確率 q で駒種を挿入する。評価時の履歴には入れない
- **線形プローブ。** モデルを固定し、隠れ状態だけを入力とする線形分類器

詳しい定義は[research_overview.md](research_overview.md)第2節と第5節にあります。

### 3 実験と考察

**ここが本体です。** 順に書きます。

1. **実験条件。** 4条件×3シード、データの規模、モデルの構成。数値は[research_overview.md](research_overview.md)第5節の表から転記してください
2. **表を1つ。** `summary.csv`から列を選び、平均±標準偏差の形で。`baselines.csv`と`盤面macroF1_多数派`は、条件の行に混ぜず表の下に注記として置きます（どの条件でも同じ値です）
3. **表から読めること。** 200〜400字
4. **第5節に該当する注意を1行**

**表を先に作ってから文章を書いてください。** 文章を先に書くと、それに合う数値を探すことになります。

条件間の差は、必ず標準偏差と比べて書いてください（第3節）。

### 4 おわりに

何が言えて何が言えないかを分けて書きます。「読み出せた」ことと「モデルがそれを使っている」ことは別だと明示してください。

残る課題を1〜2行。盤面への介入実験と、隠れ状態の置換による検証が未実施です。

### 書く順序

3 → 1 → 4 → 2 の順が書きやすいはずです。
結果が決まらないと、はじめにで何を強調するかも決まりません。

単一シードの条件がある場合は標準偏差が空欄になります。その場合は「予備的な結果」と書き添えてください。

## 7　困ったとき

- 列の意味が分からない → `columns.csv`
- もっと細かい数値が欲しい → `student_data/summary/by_run.csv`（844列あります）
- 実験の設計を知りたい → [research_overview.md](research_overview.md)第5節
- 何を主張してよいか → [research_overview.md](research_overview.md)第9節
- 引用する論文を探したい → [research_overview.md](research_overview.md)第7節
